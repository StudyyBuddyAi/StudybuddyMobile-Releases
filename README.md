# StudyBuddy AI for Android: releases

Signed Android APKs of [StudyBuddy AI](https://www.studyybuddyai.com). The source code is private; this repository holds only the release files.

**[Download the latest release →](https://github.com/StudyyBuddyAi/StudybuddyMobile-Releases/releases/latest)**

- Most phones: `StudyBuddy-<version>-arm64-v8a.apk`. If unsure, or it says the app isn't compatible, use the `universal` APK.
- Android 7.0 or newer.
- Each release lists the SHA-256 of every file (also in `SHA256SUMS.txt`).
- GitHub and Play Store installs are signed with different keys, so they can't update each other. To switch, uninstall the app first.

Privacy policy: https://www.studyybuddyai.com/privacy
